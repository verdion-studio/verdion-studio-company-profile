# Project Rules: Veridion Studio Platform

## Karakteristik Proyek
- **Tujuan**: Platform Web Company Profile sekaligus Interactive App Request System untuk Veridion Studio.
- **Arsitektur**: Statis, berfokus penuh pada **SEO (Search Engine Optimization)** dan performa Core Web Vitals tertinggi.
- **Tech Stack yang Dipilih**:
  - **Astro** (Zero JavaScript by default, HTML static output, kecepatan instan).
  - **Tailwind CSS** (Utility-first styling, desain modern ala tech-studio terkini).
  - **Lucide Icons** (Ikonografi modern dan ringan).
  - **Client-Side Interactive Islands** (Hanya untuk kalkulator/wizard request aplikasi interaktif).
- **Backend & Database**: Tanpa database (Zero DB). Semua pengajuan/lead diarahkan langsung ke WhatsApp dengan teks terformat rapi dan email (`mailto:`).

## Panduan Desain & UX
- **Nuansa Visual**: Modern Tech Studio (Dark Slate / Deep Navy dengan aksen Emerald Green / Cyan & Glassmorphism subtle).
- **Struktur Halaman Utama**:
  1. *Hero Section*: Value proposition tajam + Hook kuota Early Partner (Gratis 3 Klien Pertama).
  2. *Live Case Study*: Showcase nyata **CV Pelangi Efrata** (POS Kasir & Web Company Profile aktif).
  3. *Solusi Industri*: Spesifik UMKM (Cafe/Resto, Apotik, Hotel, Retail).
  4. *Early Partner Banner*: Live slot indicator (3/3 kuota tersedia).
  5. *Interactive App Request Wizard*: Pemilihan industri, fitur, dan estimasi preferensi.
  6. *CTA & Direct Contact*: Tombol direct WhatsApp dan Email tim Veridion.
