# Agent CLI Observability & Analytics Skill

## Solusi Observabilitas Ringan (Privacy-Friendly)
- **Plausible Analytics** atau **Cloudflare Web Analytics**: Sangat ringan ($< 1$ KB), tanpa cookie GDPR banner, tidak memperlambat loading situs.
- **Event Tracking**:
  - Event `early_partner_click`: Pengunjung menekan tombol klaim kuota 3 klien pertama.
  - Event `wizard_step_complete`: Pengunjung menyelesaikan langkah kustomisasi aplikasi.
  - Event `whatsapp_submit`: Pengunjung mengklik submit pengajuan ke WhatsApp.
