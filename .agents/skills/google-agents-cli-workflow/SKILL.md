# Agent CLI Workflow Skill

## Alur Kerja Terstruktur (Sprint Plan)

### Step 1: Scaffolding & Design Foundation
- Inisialisasi proyek Astro + Tailwind CSS.
- Konfigurasi tema warna (Midnight Slate, Electric Cyan, Emerald Growth).
- Setup font modern (Inter / Plus Jakarta Sans) dan favicon.

### Step 2: Content & Asset Integration
- Masukkan profil portofolio CV Pelangi Efrata (POS & Web).
- Tulis copywriting bernada solutif, percaya diri, dan relevan dengan UMKM lokal.

### Step 3: Interactive App Request Wizard
- Bangun alur 4 langkah pemilihan kustomisasi aplikasi.
- Implementasi generator WhatsApp link dengan pesan terstruktur otomatis.

### Step 4: SEO, Lighthouse & Verification
- Terapkan Open Graph, Twitter cards, dan sitemap generator.
- Uji skor performa (Core Web Vitals) & audit responsivitas mobile.
