# Agent CLI Evaluation Skill

## Metrik Evaluasi Kunci
1. **Lighthouse Score**:
   - Performance: Target $\ge$ 95
   - Accessibility: Target 100
   - Best Practices: Target 100
   - SEO: Target 100
2. **Core Web Vitals**:
   - LCP (Largest Contentful Paint): $< 2.5s$
   - INP (Interaction to Next Paint): $< 200ms$
   - CLS (Cumulative Layout Shift): $< 0.1$
3. **Form & Conversion Flow**:
   - Uji coba form wizard: pastikan tautan WhatsApp ter-encode dengan benar pada perangkat mobile maupun desktop.
