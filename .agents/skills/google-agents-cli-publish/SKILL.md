# Agent CLI Publish Skill

## Prosedur Publikasi Konten & Update Portofolio
1. **Penambahan Portofolio Baru**:
   - Tambahkan entri baru ke `src/data/portfolio.ts`.
   - Siapkan aset visual (mockup atau screenshot resolusi tinggi) di `src/assets/portfolio/`.
2. **Update Status Kuota Promo**:
   - Saat salah satu dari 3 kuota awal terisi, perbarui status slot di `src/data/promo.ts` (misal: dari 3/3 menjadi 2/3 tersisa) agar menciptakan rasa urgensi (*urgency & social proof*).
3. **Open Graph & Twitter Share Image**:
   - Pastikan gambar banner preview 1200x630 pixel tersedia di `public/og-image.jpg` dengan headline kredibilitas software house yang menarik.
